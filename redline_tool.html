Rules.md Reference

Official CAD Drawing Redlining Rules & Constraints

1. Color & Typography Rules

• Markup Color: All redlines and annotations must be in pure Red (#FF0000 / RGB: 1.0, 0.0, 0.0).

• Font Size: General notes and major callouts must have large font size: 24 pt or higher.

• Dimension Font Size: Minimum 14 pt to 24 pt bold (hebo / Helvetica Bold).

2. Revision Clouds & Strike-Through

• Strike-Through: The old value must be crossed out with a horizontal red line (width = 1.5 pt).

• Revision Cloud: A rectangular annotation with a wavy cloud border (clouds = 2, width = 1.5) surrounds both the crossed-out value and the new value.

• Placement: New dimensions are written directly above the old value (shifted 8 to 12 pt upwards).

3. Title Block & Revision History Protection

• Revision History Block: Left completely empty and unmodified.

• Title Block Revision Letter: Left exactly as-is (e.g. remains A or B with NO markings). Engineering determines major/minor revision classification.

4. Output Naming & Directory Structure

• File Naming: Output files are saved as [part_number] redlines.pdf (e.g., 93-027231 redlines.pdf).

• Backup: Original unmodified drawings are safely preserved in \backup\.

5. PDF Format & Drawing Zones

• Title Block (Bottom Right): Contains SPECIFICATION (Density & IFD) and MATERIAL. Old specs must be crossed out and updated in this exact cell (x: ~1760, y: ~1379).

• Revision History (Top Right): ECO numbers and rev bumps (x: ~1500-2400, y: ~50-180).

• Drawing Window (Center): Orthographic front view, side view, and geometry dimensions.

• Open Drawing Area (Top Center): Placement for general revision text notes (x: 950, y: 130).

6. Dimension Identification & Dual Units

• Thickness Dimension: Always identified as the smallest linear dimension on the drawing (typically on the side view, e.g. 101.60 mm = 4.0 in). Chamfers/angles (2X 38.1 X 30°) are excluded.

• Dual Units Standard: All dimension changes must list both inches and millimeters (e.g. 4.5" (114.3 mm) or 32.75" (831.9 mm)).

• Zero-Ghosting Policy: Only changes explicitly requested in the user prompt are created. No unprompted 32.75" or seam notes are injected.
